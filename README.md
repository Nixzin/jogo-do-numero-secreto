# Jogo do Número Secreto

Projeto de estudo desenvolvido durante o curso **Lógica de programação: explore funções e listas**, da Alura. Feito com HTML, CSS e JavaScript, o jogo desafia você a adivinhar um número de 1 a 10. A cada erro, a tela indica se o número secreto é maior ou menor que o seu palpite. Ao acertar, você vê quantas tentativas usou e pode iniciar uma nova partida.
